# F3 — Database Foundation

F3 xây dựng nền tảng PostgreSQL + EF Core cho Personal OS.

## Execution

```text
F0 Repository
  ↓
F1 Frontend Bootstrap
  ↓
F2 Backend Bootstrap
  ↓
F3 Database Foundation
  ↓
F4 Authentication & Authorization
  ↓
F5 App Shell + Design System
  ↓
F6 Finance MVP
```

F3 không xây toàn bộ business schema. Các bảng Finance, Personnel, Training và Military Manual chỉ được tạo khi module tương ứng bắt đầu.
